# 23 安全边界

> **本文回答**：哪些输入不可信，失败时系统往哪边走，敏感数据如何不出边界。
>
> 初稿：2026-10-22 · 最近更新：2026-10-22

## 一、信任模型

| 区域 | 信任级别 | 处理原则 |
|---|---|---|
| 客户端请求 | **不可信** | 所有字段都要校验；声明了身份就必须验证 |
| 进程间调用 | 已认证，但不默认可信 | 上下文中的身份标识必须来自认证中间件，不接受调用方自报 |
| 外部服务响应 | **不可信** | 校验结构与字段；不因来源是「合作方」就跳过 |
| 消息队列 | **不可信** | 消息可能重复、乱序、伪造或来自旧版本；消费前校验 |
| 配置与密钥 | 可信，但只在服务端 | 不进仓库、不进日志、不进响应 |
| 数据库 | 可信存储，内容不可信 | 用户写入的字段按不可信内容处理（输出编码、长度限制） |

**「内网」不是信任理由。** 任何跨进程边界的数据都要按契约校验；把内网当安全边界，会让一次 SSRF 或一个被攻陷的边车变成全站失守。

## 二、不可信输入清单

| 输入 | 必须校验 | 典型攻击 |
|---|---|---|
| 请求头：设备标识、时间戳、设备令牌 | 形态、时间窗口、签名 | 伪造访客身份、重放 |
| 请求头：`Authorization` | 令牌格式、签名、会话、设备绑定 | 令牌盗用、越权 |
| 路径参数 | 类型、范围、存在性、归属 | IDOR（直接对象引用） |
| 查询参数 | 类型、长度、枚举、分页边界 | 注入、慢查询、越界读取 |
| 请求体 | 字段白名单、类型、长度、范围 | 批量赋值、超长字段 |
| 排序 / 过滤表达式 | **服务端白名单**，不得拼入查询 | 排序字段注入 |
| 上传的字节 | 大小、类型、内容嗅探；存储键不得由客户端决定 | 路径穿越、可执行文件、存储桶污染 |
| URL（回调、图片、外链） | 协议、主机白名单、禁止内网地址 | 开放重定向、SSRF |
| 第三方响应 | 结构、必填字段、类型 | 以外部数据直接构造本地身份或权限 |
| MQ 消息 | 结构、版本兼容、字段范围 | 毒消息、伪造事件 |
| 配置文件 | 启动时校验，缺失即失败 | 静默回落默认值 |

**上传的存储键由服务端生成或规范化**。客户端传入的文件名只能作为显示名，不能参与路径拼接；`../` 与绝对路径必须在规范化后拒绝。

**分页必须有边界**：`page_size` 设上限；`page` 设合理上限。无边界的分页是一次请求打穿数据库的最短路径。

**批量赋值必须禁止**：请求体绑定到明确的字段集合，不把整个结构体直接写入模型。否则客户端可以提交 `user_id`、`role`、`is_review` 这类不该由它决定的字段。

## 三、两类凭据

| | 标识凭据 | 准入凭据 |
|---|---|---|
| 回答 | 这个请求属于哪个访客 / 设备 | 这个请求能否进入 |
| 例子 | 设备令牌 | 登录令牌、STOMP 连接令牌 |
| 失败 | 声明了才校验；失败拒绝；未声明按匿名 | 一律拒绝 |
| 是否门禁 | **否** | **是** |

**标识凭据不是门禁**：不带设备标识即可绕过，它的价值是对已配合的调用方提供额外保护，而不是阻止攻击者。用词上不称其为「准入凭据」，以免与真正的门禁混淆。

**准入凭据必须是门禁**：令牌无效、会话不存在、设备不匹配，任何一个失败都拒绝，不允许降级到匿名分支。降级等于开出一条绕过通道 —— 提交一个坏签名即可落到「未受保护」的分支。

**同一枚令牌的两种用途不能混**：登录令牌可用于准入；设备令牌只用于标识。把设备令牌当准入凭据，会让伪造的设备标识获得访问权。

## 四、失败与降级

| 依赖 / 判定 | 不可用时的方向 | 判据 |
|---|---|---|
| 会话存储 | **拒绝**（fail-closed） | 放行等于吊销机制失效 |
| 权限策略 / 角色查询 | **拒绝** | 放行等于越权 |
| 限流计数 | **放行**（显式声明） | 限流是保护性约束，不是正确性约束 |
| 设备令牌（已声明） | **拒绝** | 降级会开出绕过通道 |
| 设备令牌（未声明） | **按匿名放行** | 兼容无签名客户端与链路预取 |
| OAuth state | **拒绝** | 无法证明回调由本次授权发起 |
| 外部内容安全 API | **放行**（显式声明） | 可选的增强项不得拖垮评论主链路 |
| 邮件 / 短信服务 | **失败终态 + 可重发** | 用户必须知道没收到 |
| 对象存储 | **显式失败** | 不伪装上传成功 |
| 消息队列 | **显式「未投递」** | 不静默成功 |

**每一格都必须是显式选择。** 表中没有空格，是失败语义可评审的前提；「未定义」在故障时会被某段代码随机填上，通常是放行。

**放行必须可观测**：选择 fail-open 的路径必须记录错误与次数。放行而不记录，等于把故障藏起来，下一次评审时没人知道它发生过。

## 五、密码与敏感数据

| 数据 | 处理 |
|---|---|
| 用户密码 | bcrypt 存储；永不回显；比较使用恒定时间实现 |
| 令牌 / 刷新令牌 | 不出现在 URL、日志、错误信息；刷新走 Cookie 或请求体 |
| 设备令牌 | 服务端密钥签名；密钥可轮换 |
| OAuth 授权码 / secret | 只经服务端交换；不进前端、不进日志 |
| 上传凭据 | 短 TTL、限定存储键前缀与操作 |
| 配置中的密钥 | 由环境注入；不进仓库、不进文档、不进镜像 |
| 日志中的敏感字段 | 统一脱敏（密码、令牌、授权码、手机号、邮箱按需） |

**日志脱敏是默认行为，不是调用方记得才做。** 序列化日志对象时统一走脱敏入口；否则新增一个带密码字段的结构体，就会在第一次报错时把密码写进日志。

**错误信息不泄漏内部结构**：数据库语句、堆栈、文件路径只进服务端日志；跨进程与跨网络只返回通用文案。

## 六、注入与越权

| 面 | 规则 |
|---|---|
| SQL | 参数化查询；排序、表名、列名走白名单；禁止字符串拼接 |
| IDOR | 按 ID 查询必须同时带归属或可见性条件；读者端与管理端查询分开 |
| 批量赋值 | 请求体只绑定显式字段；状态位、归属、审核结果不接受客户端输入 |
| SSRF | 外部 URL 只允许白名单主机与公网地址；禁止 `file://`、内网段、元数据地址 |
| 开放重定向 | 回调地址由服务端配置决定，不接受请求参数 |
| XSS | 服务端输出 JSON；用户内容前端转义；富文本经过白名单清洗 |
| CSRF | Cookie 承载凭据的端点使用 `SameSite` + CSRF token；不带凭据的公开读接口不需要 |
| CORS / WebSocket Origin | 显式来源白名单；带凭据的跨域请求不得使用 `*`；WebSocket 的 Origin 与 HTTP 共用同一白名单 |

**越权的根因通常不是缺少权限中间件，而是查询条件漏了归属**：一个 `WHERE id = ?` 足以让任何登录用户读到别人的数据。查询与归属校验必须写在同一个条件里，不能先查再在内存里判断。

## 七、关键决策

### D1 声明身份必须校验，不降级

- **约束**：降级会开辟绕过通道。
- **备选**：签名不符时按匿名放行；或只在敏感接口校验。
- **选择**：未声明放行；声明即校验；失败拒绝。
- **代价**：调用方必须正确签名才能获得访客身份。
- **重审触发**：出现无法携带设备标识的合法客户端。

### D2 安全相关依赖一律 fail-closed

- **约束**：放行的后果不可撤销，拒绝的后果可恢复。
- **备选**：统一 fail-open；或按请求重要性分档。
- **选择**：会话、权限、准入凭据失败即拒绝；限流与可选增强显式放行。
- **代价**：依赖故障时部分功能不可用。
- **重审触发**：出现比拒绝更安全的降级路径。

### D3 客户端输入不参与服务端决策字段

- **约束**：归属、状态、审核结果、角色由服务端决定。
- **备选**：信任客户端并做二次校验。
- **选择**：请求体只绑定可写字段；决策字段从认证上下文或服务端状态取。
- **代价**：需要维护每个接口的可写字段集合。
- **重审触发**：出现需要客户端参与决策的协作编辑场景。

### D4 外部增强项失败不阻断主链路

- **约束**：内容安全 API 是可选增强，不是评论成立的前提。
- **备选**：失败即拒绝评论；或静默跳过。
- **选择**：放行并记录；放行是显式决策。
- **代价**：外部服务故障期间垃圾评论可能进入。
- **重审触发**：垃圾评论比例高到放行的代价不可接受。

### D5 日志脱敏在序列化层统一做

- **约束**：调用方不可能记得每次手动脱敏。
- **备选**：逐调用点脱敏；或在日志框架统一处理。
- **选择**：统一序列化入口脱敏。
- **代价**：脱敏规则需要覆盖所有敏感字段名。
- **重审触发**：出现无法按字段名识别的敏感数据。

### D6 跨域与 Cookie 采用显式白名单

- **约束**：`*` 与 `SameSite=None` 组合会把凭据暴露给任意站点。
- **备选**：允许所有来源；或完全禁用跨域。
- **选择**：显式来源白名单；带凭据请求不使用通配符。
- **代价**：新增前端域名需要改配置。
- **重审触发**：出现多域名、多端共享的合法场景。

## 八、不变量

- [ ] 声明了身份就必须验证；未声明才按匿名处理。
- [ ] 准入凭据失败一律拒绝，不降级。
- [ ] 安全相关依赖不可用时拒绝；放行只用于显式声明的保护性约束与可选增强。
- [ ] 归属、状态、审核结果、角色不接受客户端输入。
- [ ] 按 ID 查询必须同时带归属或可见性条件。
- [ ] 排序、表名、列名走白名单，不拼接用户输入。
- [ ] 上传存储键由服务端生成或规范化。
- [ ] 分页有上限；请求体有大小上限。
- [ ] 凭据与密钥不进 URL、日志、响应、仓库与文档。
- [ ] 外部 URL 只允许白名单主机与公网地址。

## 九、边界与重新审视

- **不做**：WAF、运行时 RASP、零信任网络、跨站 SSO。
- **重新审视**：出现第三方开放平台；出现富文本 / 文件预览等新的不可信内容面；外部内容安全从可选项变成准入条件。
